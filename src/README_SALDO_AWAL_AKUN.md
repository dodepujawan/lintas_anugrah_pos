# Saldo Awal Akun

Gunakan menu ini **sekali saat mulai memakai sistem** untuk memasukkan posisi akun dari neraca saldo lama. Jangan gunakan untuk transaksi harian atau pergantian tahun; saldo akun neraca akan berlanjut otomatis.

## Sebelum input

- Siapkan neraca saldo per tanggal cutover.
- Pastikan seluruh akun sudah tersedia di Master COA dan mempunyai saldo normal.
- Pisahkan saldo Debit dan Kredit. Total keduanya wajib sama.
- Rincian piutang dan hutang dimasukkan lewat menu saldo awal masing-masing, tanpa membuat jurnal kedua.

## Langkah input

1. Isi tanggal saldo awal, nomor jurnal, dan keterangan.
2. Pilih akun pada setiap baris.
3. Isi hanya salah satu kolom Debit atau Kredit per baris.
4. Tambahkan baris sampai seluruh akun tercatat.
5. Pastikan status menunjukkan **Balance**, lalu simpan sebagai Draft.
6. Periksa kembali dan Posting setelah disetujui.

## Kontrol penting

- Kas, bank, piutang, aset, hutang, modal, dan laba ditahan harus sesuai dokumen sumber.
- Jangan memasukkan akun pendapatan dan beban lama sebagai saldo awal tahun normal.
- Jika sudah diposting, koreksi melalui jurnal yang dapat ditelusuri; jangan menggandakan saldo awal.
