# Saldo Awal Hutang

Menu ini mencatat rincian faktur supplier lama yang masih belum lunas saat mulai menggunakan sistem. Data disimpan tanpa jurnal baru karena saldo akun Hutang Usaha sudah dicatat pada Saldo Awal Akun.

## Langkah input

1. Isi nomor faktur, tanggal faktur, dan jatuh tempo.
2. Pilih supplier yang benar.
3. Isi sisa hutang pada tanggal cutover.
4. Isi keterangan dokumen, lalu simpan.

## Pemeriksaan

- Nomor faktur harus unik.
- Total rincian saldo awal hutang sebaiknya dibandingkan dengan akun Hutang Usaha.
- Jangan memasukkan pembelian baru melalui menu ini.
- Hindari membuat jurnal Hutang Usaha kedua untuk rincian yang sama.
