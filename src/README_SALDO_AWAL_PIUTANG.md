# Saldo Awal Piutang

Menu ini mencatat **rincian invoice pelanggan lama yang belum lunas** pada saat mulai memakai sistem. Input ini tidak membuat jurnal baru karena nilai akun Piutang Usaha sudah berada di Saldo Awal Akun.

## Langkah input

1. Isi nomor dan tanggal faktur asli.
2. Isi tanggal jatuh tempo.
3. Pilih pelanggan yang benar.
4. Isi nominal sisa piutang pada tanggal cutover, bukan nilai awal jika sebagian sudah dibayar.
5. Tambahkan keterangan sumber dokumen bila diperlukan, lalu simpan.

## Pemeriksaan

- Nomor faktur harus unik.
- Total seluruh saldo awal piutang sebaiknya dibandingkan dengan akun Piutang Usaha.
- Jangan memasukkan invoice baru melalui menu ini; gunakan Piutang Berjalan.
- Saldo awal hanya dapat diedit sebelum ada pembayaran dan selama periodenya belum dikunci.
